# M5.4: The Trust Release (v0.4.0), Detailed Plan

**Goal:** make OpenVoiceType something a stranger can install and trust, before adding features.
- Dictated text isn't kept in logs.
- A dictation never lands in the wrong app or a password field.
- A number or a "not" can't silently change.
- The Claude call is isolated and says why it failed.
- Cleanup no longer depends on Claude alone.
- The README says honestly what the app is, and shows how well it works, and how that was measured.

**Status legend:** ☐ to do · ◐ in progress · ☑ done

**Status: ☑ Released as v0.4.0 (2026-09-25).** Planned as v0.3.0; the tag became v0.4.0.

**Why now.** An outside review of v0.2.0 (2026-09-25) found six problems. All of them held up against the code:
1. Everything depends on the Claude Code CLI.
2. The app isn't notarized.
3. Transcripts are logged in plain text by default.
4. Pasting is fragile: it goes to whatever has focus when the text is ready, with no secure-field check and a racy
   clipboard restore.
5. "Never treated as instructions" is only a prompt.
6. The README oversells the app's maturity.

The deep research of the same day ([research/2026-09-25-command-mode-and-cli.md](../research/2026-09-25-command-mode-and-cli.md))
adds three more:
- The Claude call loads the user's own CLAUDE.md and customizations.
- A held hotkey leaks its modifiers into the synthetic ⌘V.
- The CLI's `--bare` default is changing.

Command Mode ([M5.5](M5.5-command-mode-context-snippets.md)) moves to v0.5.0.

## 1. Scope decisions (2026-09-25)

| Question | Decision |
|---|---|
| Notarization | **Not now.** The maintainer decided against the Apple Developer account for now (roadmap decision 3), so the Open Anyway step stays. The README explains it plainly, and `release.sh` can already notarize once the account exists |
| Logging text | **Off by default.** The log keeps timings and outcomes only. A setting (Settings → About → "Keep dictated text in the log") turns it on for debugging. On first run, the text lines already in old logs are removed once |
| Log size | `dictate.log` and `error.log` rotate at 1 MB, keeping one previous file (at most about 2 MB each). The files are private (0600) |
| Paste target | **Pinned when recording starts:** the app, its focused window and that window's title. If any of them differs when the text is ready, the text isn't pasted. It goes on the clipboard, and the overlay says "Copied: you switched to <App>. Press ⌘V". The mode also comes from the start app, so the pre-started Claude is always the right one |
| Password fields | If the focused field is a secure text field (`AXSecureTextField`), recording doesn't start ("Not in password fields"). If one has focus when the text is ready, it isn't pasted and doesn't go on the clipboard; it stays under Copy Last in the menu |
| Clipboard restore | **After the target has read the paste**, not on a fixed 0.5 s timer. Our clipboard item hands its data over through a data provider, and the restore runs 150 ms after the target asks for it (at most 2 s). Our writes are marked `org.nspasteboard.TransientType`, `AutoGeneratedType` and `source`, so clipboard managers skip them |
| Held hotkey keys | Before ⌘V, wait until ⌃, ⌥, ⇧ and ⌘ are released (up to 0.6 s). Then post from a private event source, using the key code that types "v" in the current keyboard layout (Dvorak, AZERTY) |
| Meaning guard | After any AI cleanup, compare the raw and cleaned text: **every number** (digit groups, ignoring separators) and **every negation** (not, n't, never, cannot, without, nothing, nobody, none, neither, nor) must survive. If one disappears, and the speaker didn't correct themselves ("no", "actually", "I mean", "scratch that"…), Whisper's text is pasted instead (after the dictionary and output filter), and the overlay says why. The rejected cleanup is kept in History |
| Replace with raw text | A hotkey, **⌃⌥Z** by default (changeable in Settings → General), and a menu item. It undoes the last paste (⌘Z) and pastes Whisper's text instead, if the same app and window are still in front and it's within 2 minutes. Otherwise it copies Whisper's text and says so |
| History | The last 10 dictations (raw, cleaned, app, time), **in memory only** and never written to disk, in a menu submenu: Copy Cleaned or Copy Raw |
| Claude call | Adds `--safe-mode --disable-slash-commands` and `--system-prompt-file`, only when the installed CLI supports them (checked once per CLI version). Spike S0 measured `--safe-mode`: input tokens dropped from 624 to 487 at the same speed |
| Failing fast | `CLAUDE_CODE_MAX_RETRIES=1`, `CLAUDE_CODE_STARTUP_FAILURE_RESULTS=1`, `DISABLE_AUTOUPDATER=1`, `ENABLE_CLAUDEAI_MCP_SERVERS=false` for our calls only |
| API key guard | `ANTHROPIC_API_KEY` and `ANTHROPIC_AUTH_TOKEN` are removed from our Claude calls, so an exported key never silently switches the user to API billing. `CLAUDE_USE_API_KEY=on` in config.sh keeps them for users who want that |
| Why Claude failed | `claude_send` and the one-shot call read the stream-json `result`, `rate_limit_event`, `assistant.error` and `system/api_retry` events, and classify the failure: limit (with reset time), auth, offline, timeout, error. A limit or auth error stops waiting immediately |
| The `--bare` canary | If `-p` reports "not signed in" while `claude auth status` says signed in, the log and the overlay say Claude Code changed how scripts sign in, instead of a generic failure |
| Reporting results to the app | `dictate.sh refine` also writes a small JSON file (`VTT_RESULT_FILE`): the engine used, the Claude error and reset time, the guard reason and the rejected text. Exit codes 0, 3 and 4 stay as they are, and 5 means "the guard used Whisper's text" |
| Second cleanup provider | **An OpenAI-compatible endpoint:** Ollama, LM Studio, OpenAI, Groq, OpenRouter or any `/v1/chat/completions` server. It uses our full prompt and vocabulary, like Claude. The key is stored in the Keychain, and the app passes it for each call, never on a command line. Settings → Cleanup has presets for the base URL and a "Load Models" button (`GET /models`). S1-mini stays the offline fallback. Codex and the others come in M6 |
| Provider structure | The cleanup engines sit behind one dispatcher in `dictate.sh` (`claude`, `s1`, `openai`). Each is one function with the same contract: text on stdout, or a failure the caller falls back from |
| README | About half as long, and honest about maturity (early, one maintainer). It adds a "Which install is for me?" box, an eval table (cleanup quality, safety cases, latency with its method) and a plain privacy section. Modes, the dictionary, the CLI, configuration and troubleshooting move to `docs/GUIDE.md` |
| Install scripts | `install.sh` is for the CLI only. It downloads the **compressed** model (574 MB, the app's default) and makes S1-mini optional (`--with-s1-mini`). `build-app.sh` checks its prerequisites up front, says what it's building and how long it takes, and explains a signing failure |

## 2. Design notes

- **The meaning guard** is a Perl function in `dictate.sh` (`meaning_guard raw cleaned`).
  - **Numbers:** the multiset of digit groups in the raw text, with thousands separators removed (1,250 → 1250), must be
    contained in the cleaned text's. Numbers the cleanup *adds* (forty two → 42) are fine.
  - **Negations:** count negation words after normalizing n't → not and cannot → can not. The cleaned text must have at least
    as many.
  - **Self-corrections** (no, wait, actually, sorry, I mean, make that, scratch that, cancel that, or rather) skip the guard,
    because dropping the corrected part is the point.
  - Code mode is guarded too.
  - All 20 eval cases must pass without tripping it.
- **Pinning the target.** `PasteTarget.capture()` runs when recording starts: frontmost pid, bundle ID and name, the focused
  window (`AXUIElement`), its title with unread counts like "(3) " stripped, and whether the focused element is secure.
  `PasteTarget.check()` compares the same things at paste time. Without Accessibility, only the pid is compared (pasting
  needs Accessibility anyway).
- **The clipboard data provider.** `Paster` writes an `NSPasteboardItem` whose `.string` and `.html` come from a data provider
  object. When the target reads them, the provider schedules the restore. If nobody reads within 2 s, the restore runs anyway,
  and if the user copied something meanwhile (`changeCount` moved), it doesn't run at all.
- **The OpenAI-compatible call** is `refine_openai`, and follows the same pattern as `refine_s1`:
  - a Perl JSON body, `curl -H @<0600 header file>` (the key is never in argv), `OPENAI_TIMEOUT` (15 s);
  - `<think>` blocks stripped;
  - `temperature` 0, retried once without it if the server rejects it.
  
  Settings are `OPENAI_BASE_URL`, `OPENAI_MODEL` and `OPENAI_API_KEY` (or `VTT_OPENAI_*`, with `VTT_OPENAI_KEY_FILE` from the
  app). The online check uses the endpoint's host, and is skipped for localhost.
- **The app's result file.** `Dictation` passes `VTT_RESULT_FILE` (0600, in `$TMPDIR/voice-to-text/`) to each `refine`, reads
  it on exit, then deletes it.

## 4. Acceptance criteria

- **Logs:** a fresh dictation leaves no transcript text in `~/Library/Logs/voice-to-text/`, and old text lines are gone after
  the first run. The logs never grow past about 2 MB each.
- **Paste target:**
  - Switching apps (or Slack channels, where the window title changes) while the text is being prepared copies it instead
    of pasting it, and says so.
  - A password field is never pasted into.
  - The user's clipboard comes back after a paste, including in slow apps.
- **Meaning guard:**
  - A cleanup that drops a number or a "not" is replaced by Whisper's text, with a notice.
  - ⌃⌥Z replaces the last paste with Whisper's text.
  - The 20 eval cases never trip the guard.
- **The Claude call:**
  - Uses `--safe-mode` when available.
  - Ignores an exported API key.
  - A usage limit reads "Claude limit reached · resets <time>" (then S1-mini, or Whisper's text).
  - A sign-in problem says so.
- **The OpenAI-compatible endpoint:** an Ollama or OpenAI endpoint cleans up a dictation with the same prompt. The key never
  appears in `ps` output or in a file that outlives the call.
- **README:** half as long, with the method behind every number.
- shellcheck, the build, the snapshots, the self-test and the eval pass.
